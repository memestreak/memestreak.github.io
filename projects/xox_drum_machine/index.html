XOX Drum Machine

This is a 16-step drum sequencer in the style of Roland's 808, 909, etc. It was written with the help of Google's Antigravity AI coding assistant. The patterns are based on examples from the book "206 Patterns for Drum Machines", using the agent to convert the images to a JSON configuration file. The audio samples were pulled from various sources.
